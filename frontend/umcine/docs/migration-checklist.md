# Next.js 마이그레이션 체크리스트

## 범위와 상태

1단계는 기존 동작의 비교 기준 정리입니다.
2단계는 Next.js 기본 화면과 개발 및 빌드 환경 구성입니다.
3단계에서 실제 화면과 공통 Header를 App Router에 연결했습니다.
4단계에서 React Query Provider와 Zustand 인증 복원 및 클라이언트 접근 제어를 연결했습니다.
서버 데이터 조회와 쿠키 인증 전환은 후속 단계입니다.

아래 기대 동작은 기존 코드를 읽고 정리했습니다.
모의 API를 사용하는 Chromium 브라우저 검증은 완료했습니다.
아래 수동 체크박스는 실제 백엔드와의 연동 확인용이며 아직 수행하지 않았습니다.
기존 오류는 마이그레이션 이후 발생한 회귀와 구분해 기록합니다.

## 화면별 기준

| 화면 | URL | 코드에서 확인한 기대 동작 |
| --- | --- | --- |
| 영화 목록 | `/` | 목록과 페이지 이동. 상세 이동. 즐겨찾기 표시와 변경 |
| 영화 상세 | `/movies/{movieId}` | 상세 정보. 즐겨찾기 변경. 영화 기록과 평점 등록 및 수정과 삭제 |
| 검색 | `/search?query=검색어` | 검색어 URL 반영. 앞뒤 공백 제거. 초기화. 결과와 빈 결과 표시 |
| 로그인 | `/login` | 이메일 검사. 성공 시 토큰 저장 후 `/` 이동. 실패 알림. 로그인 사용자는 `/` 이동 |
| 회원가입 | `/signup` | 이메일과 닉네임 중복 확인. 비밀번호와 확인값 검사. 성공 후 `/login` 이동 |
| 내 정보 | `/my-info` | 회원 정보와 즐겨찾기 목록 및 페이지 이동. 상세 이동 |
| 정보 수정 | `/edit-profile` | 회원 정보 조회. 닉네임 중복 검사. 수정 후 회원 정보 캐시 갱신 |

## 실제 백엔드 수동 검증

`pnpm dev` 실행 후 Next.js 주소에서 테스트 계정으로 확인합니다.
토큰과 비밀번호는 결과에 기록하지 않습니다.

- [ ] 각 URL 직접 접속과 새로고침 및 뒤로 가기
- [ ] 영화 목록 페이지 이동과 상세 이동
- [ ] 상세 페이지의 잘못된 ID와 조회 실패 처리
- [ ] 검색 URL 반영과 새로고침 시 검색 복원
- [ ] 검색 초기화와 빈 결과 및 요청 실패 표시
- [ ] 로그인 성공과 실패 및 중복 제출 방지
- [ ] 로그인 후 새로고침 시 토큰 복원과 회원 화면 접근
- [ ] 비로그인 상태의 `/my-info`와 `/edit-profile` 접근 시 `/login` 이동
- [ ] 로그인 상태의 `/login` 접근 시 `/` 이동
- [ ] 회원가입 중복 확인과 입력 변경 시 중복 확인 상태 초기화
- [ ] 회원가입 성공 후 로그인 화면 이동
- [ ] 비로그인 상태의 즐겨찾기 클릭 시 로그인 필요 알림
- [ ] 즐겨찾기 추가와 해제 후 목록과 상세 및 내 정보 반영
- [ ] 평점 등록과 수정 및 삭제 후 최신 값 반영
- [ ] 정보 수정 후 헤더와 내 정보 화면 반영
- [ ] 느린 네트워크와 오프라인에서 로딩과 오류 표시
- [ ] 존재하지 않는 URL의 안내 화면

## 후속 작업 주의점

- 인증은 Zustand persist와 localStorage 기반입니다. 서버 인증으로 바로 대체할 수 없습니다.
- 검색 조건은 URL에 있지만 영화 목록과 즐겨찾기의 페이지 번호는 컴포넌트 상태입니다. 새로고침 시 페이지 복원은 기존 보장 사항이 아닙니다.
- 현재 코드에서 로그아웃 UI는 확인되지 않았습니다. 추가 구현은 별도 작업입니다.
- 모든 페이지는 공통 Header와 React Query Provider를 공유합니다.
- 기존 Vite 환경 변수는 Next.js 공개 환경 변수로 임시 연결합니다. API 구조는 유지합니다. TMDB 토큰 서버 분리는 후속 작업입니다.

브라우저 검증은 임시 Playwright와 Chromium을 사용했으며 프로젝트 의존성에는 추가하지 않았습니다.
외부 API는 모의 응답으로 대체했습니다. 실제 백엔드 데이터는 변경하지 않았습니다.
토큰 복원 검증도 격리된 브라우저 컨텍스트의 테스트 토큰으로 수행했습니다.
영화 목록과 상세의 모의 데이터 스크린샷으로 공통 Header와 기존 레이아웃도 확인했습니다.
실제 이미지 로딩과 백엔드 권한 검증 및 네트워크 장애 처리는 위 수동 체크리스트에 남아 있습니다.
